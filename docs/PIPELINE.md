# Content Intelligence Pipeline

## Decision flow

25 monitored creators -> niche grouping (5 each) -> recent Shorts metrics -> creator baseline -> individual breakout -> semantic topic clustering -> compare same theme across other four niche creators -> Topic Confidence -> original angle -> fact verification -> five-hook competition -> visual story engine -> Gemini 9:16 prompt -> Telegram -> human generates in Gemini -> video returned to Telegram -> correct social profile publishing -> 1h/6h/24h/72h performance feedback.

## Critical rule
A creator posting a new Short is NOT a content-generation event.

A prompt is created when:
- the Short materially outperforms that creator's baseline, AND/OR
- related content is validated across other creators in the niche, AND/OR
- early view velocity is exceptionally high.

## Learning layers
1. Individual creator performance.
2. Cross-creator topic performance.
3. Our own channel performance (becomes increasingly important after sufficient publishing history).

## Telegram content package
Each approved opportunity receives a Content ID and contains niche, source signal summary, confidence score, original angle, selected hook, voiceover, scene plan, full Gemini prompt, title, caption and hashtags.

Uploaded completed videos must be associated with the Content ID before publishing to prevent video/prompt mismatches.
